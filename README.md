# 🟣 Ultimate Stream Overlay [Twitch & OBS]

Премиальный, модульный и полностью интерактивный оверлей для стримеров на Twitch.
Написан на чистом HTML/CSS/JS без использования сторонних конструкторов (Streamlabs/StreamElements). 
Работает через локальную шину событий (Event Bus), сохраняет данные при перезагрузке, защищает личные данные и управляется прямо из чата или через отдельную Web-панель.

## ✨ Главные фишки 
* **🦊 Интерактивный Питомец:** Пиксельная лисичка сидит на рамке вебки. Она засыпает в тишине, танцует под музыку, пугается хорроров (когда добавляют смерть), злится на мат в чате и пускает сердечки при сабках.
* **🎵 Умный YouTube-плеер:** Заказы музыки за Баллы Канала. Умеет играть целые плейлисты. Имеет функцию Audio Ducking (автоматически приглушает музыку во время алертов и озвучки).
* **🛡️ Приватный режим (Security Screen):** Мгновенная непрозрачная заглушка экрана (`!blur`) для безопасного ввода паролей.
* **💬 Продвинутый Чат:** Плавная анимация, поддержка ответов (реплаев), встроенный фильтр мата и уникальные CSS-стили баблов для VIP-зрителей.
* **🕹️ Глобальные Темы:** Полное изменение дизайна стрима одной командой (например, превращение стрима в черно-белый нуар-комикс).
* **📱 Панель Модератора (Mod Deck):** Удаленное управление стримом с телефона или второго монитора.

## 📺 Установка в OBS Studio (Архитектура «Мозг и Монитор»)

Проект разделен на два источника, чтобы при смене сцен музыка не прерывалась.

### Шаг 1: Установка ЯДРА (Мозг)
1. В OBS создай источник **«Браузер»** и назови его `[ USO CORE ]`.
2. Укажи локальный путь к файлу **`core.html`**.
3. ⚠️ **КРИТИЧЕСКИ ВАЖНО:** Поставь галочку **«Управление аудио через OBS»**. Без неё браузер заблокирует звук музыки и TTS!
4. В микшере звука OBS нажми шестеренку у `[ USO CORE ]` -> Фильтры -> Добавь **«Усиление» на +10 dB**.
5. Добавь Ядро на одну общую сцену (или сделай глобальным источником).

### Шаг 2: Установка ВИЗУАЛА (Монитор)
1. Создай источник **«Браузер»** и назови его `[ USO OVERLAY ]`.
2. Укажи локальный путь к файлу **`index.html`**.
3. Размер строго **1920x1080**.
4. Поставь галочку **«Обновлять браузер, когда сцена становится активной»**.
5. *Параметры сцен:* В конец пути можно дописать параметры для переключения режимов:
   * Обычная игра (дефолт): `.../index.html`
   * Сцена общения (Just Chatting): `.../index.html?scene=chatting`
   * Сцена ожидания (Начало): `.../index.html?scene=starting`
   * Сцена завершения: `.../index.html?scene=ending`

## 📱 USO Mod Deck (Локальная Панель Модератора)

Чтобы не писать команды в чат вручную, используйте пульт управления:
1. Откройте файл `mod-deck.html` в браузере (на ПК, планшете или телефоне).
2. Введите имя канала стримера и свой Twitch никнейм.
3. Нажмите на ссылку **«ПОЛУЧИТЬ ТОКЕН ТУТ»**.
4. На открывшемся сайте (TwitchTokenGenerator) выберите карточку с зеленым роботом **«Bot Chat Token»** и авторизуйтесь.
5. Скопируйте длинный код из поля *ACCESS TOKEN* (`g128h381...`) и вставьте в панель.
6. Нажмите **ПОДКЛЮЧИТЬ ПАНЕЛЬ**. Теперь нажатие кнопок на пульте будет моментально управлять оверлеем в OBS!

## 🎮 ПОЛНЫЙ СПИСОК КОМАНД СИСТЕМЫ

🟢 **Для всех зрителей:**
* `!play [ссылка]` или `!sr [ссылка]` — заказ трека/плейлиста с YouTube.

🔴 **Только для Модераторов и Allowed Users:**

### 🎵 Музыка и Озвучка (TTS)
* `!skip` — пропустить текущий трек.
* `!skip all` — пропустить весь заказ (весь плейлист).
* `!clear` — очистить очередь музыки.
* `!vol [0-100]` — громкость плеера (например: `!vol 25`).
* `!tts [текст]` — принудительно озвучить текст ботом.
* `!tts stop` (или `!tts skip`) — заткнуть бота (сброс очереди TTS).

### 🛡️ Визуал, Камера и Приватность
* `!blur on` / `!blur off` (или `!блюр`) — включить/выключить стильный защитный экран (пароли/бан-ворды).
* `!cam on` / `!cam off` — показать/скрыть неоновую рамку вебкамеры.
* `!mic on` / `!mic off` — включить/отключить пульсацию рамки вебки от голоса стримера.
* `!emotes a` (или `bubble`) — режим смайлов: мыльные пузыри.
* `!emotes b` (или `fountain`) — режим смайлов: фонтан.
* `!emotes off` / `!emotes on` — выключить/включить смайлики на экране.

### ⚙️ Управление виджетами (Скрыть/Показать ЛЮБОЙ элемент)
Команда: `!widget [имя_виджета] [on/off]` (или `show/hide`).
**Список всех доступных названий виджетов:**
* `chat` — Чат
* `music` — Музыкальный плеер YouTube
* `socials` — Ротатор соцсетей
* `alerts` — Система алертов
* `shoutout` — Плашка рекламы стримеров
* `goal` — Полоска цели (фолловеры)
* `ticker` — Бегущая строка внизу
* `deaths` — Счетчик смертей
* `particles` — Фоновые летающие частицы
* `emotes` — Летящие смайлы из чата
* `tts` — Плашка эквалайзера озвучки
* `blur` — Защитный экран
* `wheel` — Колесо фортуны
* `cam` — Рамка вебкамеры
* `media` — Плашка "Сейчас играем/смотрим"
* `pet` — Питомец (Лиса)

*Пример: `!widget chat off` (Спрячет чат), `!widget goal on` (Покажет полоску цели).*

### 🎨 Глобальные Темы Стрима
Команда: `!протокол [название]` (или `!protocol`).
* `!протокол цирк` — Тема "Удивительный Цифровой Цирк" (красно-сине-желтая).
* `!протокол нуар` — Тема "Spider-Noir" (черно-белый газетный комикс).
* `!протокол отмена` (или `default`, `off`) — Возврат к дефолтной неоновой теме.

### 🕹️ Система (Сброс кэша)
* `!refresh` — Мягкая перезагрузка визуала (сброс застрявших картинок).
* `!refresh core` — Жесткая перезагрузка аудио-ядра (сброс плеера).

### 🎡 Колесо Фортуны (Рулетка)
* `!wheel show` / `!wheel hide` — показать/спрятать колесо на экране.
* `!wheel spin` — крутить колесо!
* `!wheel add [текст]` — добавить вариант в колесо вручную.
* `!wheel remove [номер или текст]` — удалить вариант (например: `!wheel remove 1`).
* `!wheel clear` — полностью очистить колесо.

### 💀 Счетчик смертей (Сохраняется после перезапуска)
* `!death` (или `!deaths`, `!смерть`) — +1 смерть (экран затрясется, лиса испугается).
* `!death -` (или `!death sub`) — отнять 1 смерть.
* `!death set [число]` — установить точное значение (например: `!death set 15`).
* `!death reset` (или `!death clear`) — сбросить счетчик в 0.

### 🦊 Управление Питомцем (Лисой)
Команда: `!fox [эмоция]` (или `!лиса`, `!лис`)
* **Эмоции:** `sleep` (сон), `hype` (радость), `love` (сердечки), `scared` (страх), `angry` (злость).
* **Действия:** `jam` (танцует), `listen` (слушает), `nom` (кушает), `greet` (привет), `bye` (пока).
* **Синонимы:** `!fox кусь` (или `ням`), `!fox привет`, `!fox пока`, `!fox танцуй` (или `вайб`), `!fox idle` (покой).

### 📢 Реклама стримеров (Shoutout)
* `!so [никнейм]` (или `!shoutout [ник]`) — красивая 3D-карточка рекламы стримера с его аватаркой и категорией.

## 🧪 ТЕСТОВЫЕ КОМАНДЫ (ДЛЯ НАСТРОЙКИ СТРИМА)

Используйте эти команды для проверки визуала без ожидания реальных зрителей.

### 1. Тест Алертов
* `!alert sub` — Обычная подписка
* `!alert resub` — Продление (Ресаб)
* `!alert gift` — Подарочная подписка
* `!alert streak` — Стрик просмотра
* `!alert follow` — Новый фолловер
* `!alert series` / `!alert movie` / `!alert video` / `!alert game` / `!alert music` — Тест наград за баллы канала.

### 2. Тест VIP-Баблов (Кастомные стили чата)
Специальные команды, которые имитируют сообщение от конкретного пользователя с его уникальным дизайном:
* `!testhk` — **bagercaa** (Стиль: Hollow Knight, темная душа).
* `!testmc` — **kiriika1** (Стиль: Minecraft Dirt Block, воксели).
* `!testangel` — **to_be_ang** (Стиль: Ангел, золото, левитация, нимб).
* `!testbendy` — **dragonsmaddison** (Стиль: Bendy 1930s, старая пленка).
* `!testhacker` — **tetlabot** (Стиль: Хакерский терминал).
* `!testarmy` — **darkl1us** (Стиль: Tactical HUD, ПНВ).
* `!testpda` — **ksusha__sher** (Стиль Владельца канала, неон).

### 3. УМНЫЕ ФЛАГИ ДЛЯ ТЕСТА (Магия парсера)
Вы можете добавлять специальные скрытые «флаги» в тестовые команды, чтобы сымитировать сложные ситуации в чате (реплаи, пинги, первое сообщение).

**Доступные флаги:**
* `-rep` — имитирует, что сообщение является ответом (Reply) на чей-то чужой текст.
* `-hl` — имитирует Выделенное сообщение (Highlight за баллы).
* `-ping` — имитирует упоминание (Пинг) стримера через @.
* `-first` — добавляет бейдж "Впервые в чате".
* `-tts` — заставляет Ядро одновременно с выводом в чат прочитать этот текст голосом бота.

**Как это использовать (Примеры):**
* `!testhk -rep -hl Привет!` — Отправит бабл в стиле Hollow Knight, который будет светиться (как за баллы) и у него сверху будет плашка ответа на сообщение.
* `!testmc -first -ping Эй, обернись!` — Отправит бабл Minecraft с бейджем "Впервые в чате" и красным пингом стримера.
* `!testhacker -tts Взлом системы завершен.` — Отправит сообщение в стиле Терминала и бот зачитает этот текст вслух!
* `!testfirst` / `!testmention` / `!testhighlight` — Базовые быстрые тесты дефолтного чата без кастомных стилей.

### 4. Тест кастомного голоса
* `!testtts [никнейм] [текст]` — Принудительно запустить озвучку от лица конкретного юзера (чтобы проверить его кастомную высоту голоса (pitch) и скорость, заданные в `config.js`). Например: `!testtts to_be_ang Привет всем`.
