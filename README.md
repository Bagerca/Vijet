# 🟣 Ultimate Stream Overlay [Twitch & OBS]

Премиальный, модульный и полностью интерактивный оверлей для стримеров на Twitch. 
Написан на чистом HTML/CSS/JS без конструкторов (Streamlabs/StreamElements). 
Работает через локальную шину событий (Event Bus), сохраняет данные при перезагрузке и управляется прямо из чата!

## ✨ Главные фишки
* **🦊 Интерактивный Питомец:** Пиксельная лисичка сидит на рамке вебки и реагирует на стрим: засыпает в тишине, танцует под музыку, пугается хорроров, злится на мат в чате и пускает сердечки при подписках!
* **🎵 Умный YouTube-плеер с Плейлистами:** Заказы музыки за Баллы Канала. Поддерживает как одиночные видео, так и **целые плейлисты**. Сам переключает треки, показывает прогресс-бар и имя заказчика.
* **🎡 Колесо Фортуны:** Встроенная рулетка на экране. Зрители могут добавлять варианты за баллы канала, а модераторы крутить её прямо из чата.
* **💾 Защита от перезагрузок (LocalStorage):** Очередь музыки, рулетка, счетчик смертей и аватарки зрителей кэшируются. Если моргнет интернет или обновится источник — ничего не пропадет!
* **💬 Умный Чат:** Плавная анимация, парсинг всех Twitch-эмодзи, поддержка ответов (реплаев) и система блюра запрещенных слов (защита от банов).
* **🎙️ Озвучка чата (TTS):** Встроенный синтезатор речи с визуальным эквалайзером и поддержкой кастомных голосов (тональность и скорость) для избранных зрителей.
* **🎮 Динамическое Инфо Игры:** Плашка над вебкой, которая сама подтягивает обложку, рейтинг и год выхода игры из Steam по команде `!game`.

## 🛠️ Как настроить перед запуском
Открой файл `js/config.js` через любой текстовый редактор.
Что нужно обязательно изменить:
* `channelName: "ТВОЙ_НИК"` — впиши свой ник на Twitch (маленькими буквами).
* Названия наград (`rewardName`, `ttsRewardName`, `wheelRewardName`) — создай награды на Twitch с точно такими же названиями, чтобы скрипт мог их ловить.

## 📺 Правильная установка в OBS Studio (ВАЖНО!)

Проект использует профессиональную архитектуру **«Мозг и Монитор»**, состоящую из двух файлов. Это сделано для того, чтобы при смене сцен в OBS музыка не прерывалась, а очередь не сбрасывалась.

### Шаг 1: Установка ЯДРА (Мозг)
1. В OBS создай источник **«Браузер»** (Browser Source).
2. Назови его `[ USO CORE ]`.
3. Укажи локальный путь к файлу **`core.html`**.
4. ⚠️ **КРИТИЧЕСКИ ВАЖНО:** Поставь галочку **«Управление аудио через OBS»** (Control audio via OBS). Без неё браузер заблокирует фоновое воспроизведение звука и плеер не заработает!
5. Этот источник можно добавить на одну главную сцену или сделать глобальным. Его не видно на экране (размер 1x1 пиксель), он только слушает Twitch и играет музыку.

### Шаг 2: Установка ВИЗУАЛА (Монитор)
1. Создай еще один источник **«Браузер»** и назови его `[ USO OVERLAY ]`.
2. Укажи локальный путь к файлу **`index.html`**.
3. Размер строго **1920x1080**.
4. Поставь галочку **«Обновлять браузер, когда сцена становится активной»**.
5. *Опционально:* Оверлей поддерживает модульность! Ты можешь добавить его по частям. В конце ссылки добавь параметры, например:
   * Только Чат: `.../index.html?widget=chat`
   * Только Плеер: `.../index.html?widget=music`
   * Сцена Just Chatting: `.../index.html?scene=chatting`

## 🎮 Команды Чата

🟢 **Для всех зрителей:**
* `!play [ссылка]` или `!sr [ссылка]` — добавить трек или плейлист в очередь (если включено для всех).

🔴 **Только для Модераторов и Стримера:**

🎵 **Музыка и TTS:**
* `!skip` — пропустить текущий трек (если играет плейлист — включится следующий трек внутри него).
* `!skip all` — выбросить весь текущий плейлист целиком и перейти к заказу следующего зрителя.
* `!clear` — полностью очистить очередь и остановить плеер.
* `!vol [0-100]` — изменить громкость музыки.
* `!tts [текст]` — бесплатная озвучка сообщения (для тестов/модеров).
* `!tts stop` — заткнуть бота, если заказали спам.

🎡 **Колесо Фортуны (Рулетка):**
* `!wheel show` / `!wheel hide` — показать/спрятать колесо на экране.
* `!wheel spin` — крутить колесо!
* `!wheel add [текст]` — добавить вариант в рулетку вручную.
* `!wheel remove [номер или текст]` — удалить вариант (например: `!wheel remove 1`).
* `!wheel clear` — полностью очистить колесо.

🎥 **Визуал и Вебкамера:**
* `!game [название]` — показать красивую плашку с постером игры над вебкой (например: `!game subnautica`).
* `!game off` — спрятать плашку игры.
* `!blur on` / `!blur off` — включить стильный "Приватный режим" (размытие экрана для ввода паролей).
* `!cam off` / `!cam on` — скрыть/показать рамку вебки.
* `!emotes a` (пузыри) / `!emotes b` (фонтан) / `!emotes off` — управление летящими смайлами.

💀 **Счетчик смертей (сохраняется в памяти):**
* `!death` — +1 смерть (Питомец испугается, счетчик затрясется).
* `!death -` — отнять 1 смерть.
* `!death set 15` — установить точное количество смертей.
* `!death reset` — сбросить счетчик в 0.
* `!death hide` / `!death show` — принудительно скрыть/показать.

🦊 **Управление Питомцем (Лисой):**
* `!fox [эмоция]` — принудительно вызвать анимацию. Доступные: `idle, sleep, alert, hype, love, scared, angry, greet, bye, jam, listen, nom`.
* Синонимы: `!fox кусь`, `!fox танцуй`, `!fox привет`.

🔔 **Инструменты стримера:**
* `!so @никнейм` — красивая 3D-карточка рекламы другого стримера.
* Тесты алертов: `!alert sub`, `!alert gift`, `!alert streak`.
