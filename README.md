# 🟣 Ultimate Stream Overlay [Twitch & OBS]

Премиальный, модульный и полностью интерактивный оверлей для стримеров на Twitch. 
Написан на чистом HTML/CSS/JS без конструкторов (Streamlabs/StreamElements). 
Работает через локальную шину событий (Event Bus), сохраняет данные при перезагрузке, имеет защиту личных данных и управляется прямо из чата!

## ✨ Главные фишки
* **🦊 Интерактивный Питомец:** Пиксельная лисичка сидит на рамке вебки и реагирует на стрим: засыпает в тишине, танцует под музыку, пугается хорроров, злится на мат в чате и пускает сердечки при подписках.
* **🎵 Умный YouTube-плеер:** Заказы музыки за Баллы Канала. Поддерживает одиночные видео и **целые плейлисты**. Сам переключает треки, синхронизирует тайминги картинки и звука.
* **🛡️ Приватный режим (Security Screen):** Мгновенная 100% непрозрачная заглушка экрана с эффектом сканера по команде `!blur`, чтобы безопасно вводить пароли на стриме.
* **🎡 Колесо Фортуны:** Встроенная рулетка на экране. Зрители добавляют варианты за баллы канала, а модераторы крутят её из чата.
* **💬 Умный Чат и Кастомные стили:** Плавная анимация, парсинг Twitch-эмодзи, поддержка ответов (реплаев), умный фильтр мата и уникальные CSS-стили баблов для VIP-зрителей.
* **🎙️ Озвучка чата (TTS):** Встроенный синтезатор речи с визуальным эквалайзером и кастомными голосами (тональность и скорость).
* **🎮 Динамическое Инфо Игры:** Независимая плашка с постером, рейтингом и жанром игры.

## 🛠️ Как настроить перед запуском
Открой файл `js/config.js` через любой текстовый редактор. Что нужно обязательно изменить:
* `channelName: "ТВОЙ_НИК"` — впиши свой ник на Twitch (строчными буквами).
* `allowedUsers` — список ников модераторов/друзей, которым разрешено управлять оверлеем без прав модератора Twitch.
* Названия наград (`rewardName`, `ttsRewardName`, `wheelRewardName` и т.д.) — создай награды на Twitch с точно такими же названиями.

## 📺 Установка в OBS Studio (Архитектура «Мозг и Монитор»)

Проект использует профессиональную архитектуру из двух файлов. Это сделано для того, чтобы при смене сцен в OBS музыка не прерывалась, а очередь не сбрасывалась.

### Шаг 1: Установка ЯДРА (Мозг)
1. В OBS создай источник **«Браузер»** (Browser Source) и назови его `[ USO CORE ]`.
2. Укажи локальный путь к файлу **`core.html`**.
3. ⚠️ **КРИТИЧЕСКИ ВАЖНО:** Поставь галочку **«Управление аудио через OBS»**. Без неё браузер заблокирует звук!
4. В микшере звука OBS нажми на шестеренку у `[ USO CORE ]` -> Фильтры -> Добавь **«Усиление» (Gain) на +10 dB** (чтобы TTS и звуки алертов было хорошо слышно).
5. Ядро невидимое. Добавь его на одну общую сцену.

### Шаг 2: Установка ВИЗУАЛА (Монитор)
1. Создай источник **«Браузер»** и назови его `[ USO OVERLAY ]`.
2. Укажи локальный путь к файлу **`index.html`**.
3. Размер строго **1920x1080**.
4. Поставь галочку **«Обновлять браузер, когда сцена становится активной»**.
5. *Модульность:* В конце ссылки можно добавить параметры сцен:
   * Обычная игра: `.../index.html`
   * Сцена общения: `.../index.html?scene=chatting`
   * Сцена ожидания: `.../index.html?scene=starting`
   * Завершение: `.../index.html?scene=ending`

## 🎮 ПОЛНЫЙ СПИСОК КОМАНД

🟢 **Для всех зрителей:**
* `!play [ссылка]` или `!sr [ссылка]` — добавить трек или плейлист YouTube в очередь.

🔴 **Только для Модераторов, Стримера и Allowed Users:**

### 🎵 Музыка и Озвучка (TTS)
* `!skip` — пропустить текущий трек (или включить следующий внутри плейлиста).
* `!skip all` — полностью пропустить текущий плейлист/заказ зрителя.
* `!clear` — полностью очистить очередь и остановить музыку.
* `!vol [0-100]` — изменить громкость плеера (например: `!vol 25`).
* `!tts [текст]` — принудительная бесплатная озвучка сообщения.
* `!tts stop` (или `!tts skip`) — заткнуть бота, если заказали спам или слишком длинный текст.

### 🛡️ Визуал и Защита (Камера, Блюр, Смайлы)
* `!blur on` / `!blur off` (или `!блюр`) — включить/выключить стильный 100% непрозрачный защитный экран для ввода паролей.
* `!cam on` / `!cam off` — показать/скрыть неоновую рамку вебкамеры (питомец скроется вместе с ней).
* `!mic on` / `!mic off` — включить/отключить пульсацию рамки вебки от голоса.
* `!emotes a` (или `!emotes bubble` / `!смайлы a`) — режим летящих смайликов: мыльные пузыри.
* `!emotes b` (или `!emotes fountain` / `!смайлы b`) — режим летящих смайликов: фонтан.
* `!emotes off` / `!emotes on` — выключить/включить смайлики на экране.
* `!refresh` — перезагрузить визуал оверлея (сброс кэша картинок).
* `!refresh core` — жесткая перезагрузка Ядра (музыки).

### 🎡 Колесо Фортуны (Рулетка)
* `!wheel show` / `!wheel hide` (или `!рулетка on/off`) — показать/спрятать колесо на экране.
* `!wheel spin` (или `!рулетка spin`) — крутить колесо!
* `!wheel add [текст]` — вручную добавить вариант в колесо.
* `!wheel remove [номер или текст]` — удалить вариант (например: `!wheel remove 1`).
* `!wheel clear` — полностью очистить колесо.

### 💀 Счетчик смертей (Сохраняется после перезапуска)
* `!death` (или `!deaths`, `!смерть`) — добавить +1 смерть (экран затрясется, лиса испугается).
* `!death -` (или `!death sub`) — отнять 1 смерть (если мисскликнул).
* `!death set [число]` — установить точное значение (например: `!death set 15`).
* `!death reset` (или `!death clear`) — сбросить счетчик в 0.
* `!death hide` / `!death show` (или `!death off/on`) — принудительно скрыть/показать счетчик.

### 🦊 Управление Питомцем (Лисой)
Команда: `!fox [эмоция]` (или `!лиса`, `!лис`)
* **Базовые:** `idle` (покой), `sleep` (сон), `alert` (внимание), `hype` (радость), `love` (сердечки), `scared` (страх), `angry` (злость).
* **Действия:** `jam` (танцует), `listen` (слушает), `nom` (кушает), `greet` (привет), `bye` (пока).
* **Русские синонимы:** `!fox кусь` (или `ням`), `!fox привет`, `!fox пока`, `!fox танцуй` (или `вайб`).

### 🎮 Инфо Игры (Плашка игры)
* `!game [название]` (или `!игра [название]`) — показать плашку с игрой. Ищет в локальной базе или качает из Steam.
* `!game off` (или `!game clear`, `!game hide`) — скрыть плашку игры.

### 📢 Реклама стримеров (Shoutout)
* `!so [никнейм]` (или `!shoutout [ник]`) — красивая 3D-карточка рекламы другого стримера с его аватаркой, категорией и фолловерами.
