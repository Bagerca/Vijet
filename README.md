# 🟣 Ultimate Stream Overlay [Twitch & OBS]

Премиальный, модульный и полностью интерактивный оверлей для стримеров на Twitch. 
Написан на чистом HTML/CSS/JS, без использования конструкторов типа Streamlabs или StreamElements. Работает молниеносно, выглядит стильно (Glassmorphism) и управляется прямо из чата!

## ✨ Главные фишки
* **Разделение на виджеты:** Можно вставить в OBS как всё сразу одной ссылкой, так и разделить каждый элемент на свой независимый слой.
* **🎵 Интерактивный плеер YouTube:** Зрители заказывают музыку за Баллы Канала или командой в чате. Скрипт сам проигрывает видео, показывает прогресс-бар и переключает треки.
* **🎙️ "Живая" Вебкамера:** Рамка веб-камеры пульсирует и светится в такт твоему голосу (встроенный эквалайзер микрофона).
* **💬 Умный Чат:** Кэширование аватарок, поддержка всех Twitch-эмодзи, плавная анимация появления и исчезновения старых сообщений.
* **📢 Shoutout-система:** Красивое 3D-представление других стримеров на экране с автоматическим парсингом их аватарок по нику.
* **💀 Интерактивный счетчик смертей:** Минималистичный текстовый дизайн с глич-эффектами при получении урона.
* **И многое другое:** Система алертов (подписки, фолловы, гифты), ротатор соцсетей, бегущая строка с новостями, динамическая полоса цели фолловеров.

## 🛠️ Как настроить перед запуском

Открой файл `js/config.js` через любой текстовый редактор (например, Блокнот или VS Code).
Это главный пульт управления оверлеем. 

**Что нужно обязательно изменить:**
1. `channelName: "ТВОЙ_НИК"` — впиши сюда свой ник на Twitch (строго маленькими буквами).
2. `rewardName: "Заказать видео"` — если хочешь, чтобы зрители заказывали музыку за баллы канала, создай награду на Twitch с **точно таким же названием**.
3. Настрой свои соцсети, бегущую строку и Цель фолловеров под себя.

## 📺 Установка в OBS Studio

Добавлять оверлей нужно через источник **«Браузер» (Browser Source)**.
У тебя есть **два пути**, как это сделать:

### Вариант 1: «Всё в одном» (Быстро)
Просто создай один источник «Браузер», укажи размер `1920x1080` и вставь основную ссылку:
`https://твой-ник.github.io/Vijet/index.html`

### Вариант 2: «Модульный» (Рекомендуется)
Если ты хочешь управлять чатом, музыкой и алертами по отдельности (например, наложить на музыку фильтр или сделать чат полупрозрачным в OBS), добавь каждый элемент как **отдельный источник «Браузер»**.

⚠️ **ВАЖНО:** Для КАЖДОЙ ссылки ниже размер в OBS должен быть строго `1920x1080`! Элементы появятся на своих правильных местах.

* **Чат:** `.../index.html?widget=chat`
* **Алерты:** `.../index.html?widget=alerts`
* **Музыкальный плеер:** `.../index.html?widget=music`
* **Цель (Goal):** `.../index.html?widget=goal`
* **Рамка Вебки (Эквалайзер):** `.../index.html?widget=cam`
* **Социальные сети:** `.../index.html?widget=socials`
* **Счетчик смертей:** `.../index.html?widget=deaths`
* **Бегущая строка:** `.../index.html?widget=ticker`
* **Shoutout (Реклама стримеров):** `.../index.html?widget=shoutout`
* **Фон (Частицы):** `.../index.html?widget=particles`

*(Не забудь поставить галочку "Отключать источник, когда он не виден" в свойствах источника OBS).*

## 🎮 Команды Чата

Оверлей слушает чат Twitch в реальном времени. Вот список доступных команд:

### 🟢 Для всех зрителей:
* `!play [ссылка на YouTube]` — добавить трек в очередь (если включено).
* `!sr [ссылка на YouTube]` — то же самое, что и !play.

### 🔴 Только для Модераторов и Стримера:
**🎵 Управление музыкой:**
* `!skip` — пропустить текущий трек и включить следующий.
* `!clear` — полностью очистить очередь заказов.
* `!vol [0-100]` — изменить громкость плеера (например: `!vol 50`).

**💀 Счетчик смертей:**
* `!death` (или `!смерть`) — добавить +1 смерть (счетчик появится автоматически с красной вспышкой).
* `!death -` — отнять 1 смерть (если добавили случайно).
* `!death set [число]` — установить точное количество (например: `!death set 15`).
* `!death reset` — сбросить счетчик до нуля.
* `!death hide` / `!death show` — принудительно спрятать или показать счетчик на экране.

**🎥 Управление визуалом:**
* `!so @никнейм` — запустить красивую карточку Shoutout для другого стримера.
* `!cam off` / `!cam on` — скрыть или показать рамку веб-камеры.
* `!mic off` / `!mic on` — выключить/включить реакцию рамки вебки на твой голос.

**🔔 Тестирование Алертов:**
* `!alert` — тест обычного фолловера.
* `!alert sub` — тест платной подписки.
* `!alert resub` — тест переподписки (с указанием месяцев).
* `!alert gift` — тест подарочной подписки.

## ⚙️ Технологии под капотом
* **ComfyJS** — для мгновенного подключения к чату Twitch (без токенов и авторизаций).
* **YouTube Iframe API** — для воспроизведения музыки.
* **IVR API** (`api.ivr.fi`) — для получения аватарок и цветов профилей пользователей.
* **Web Audio API** — для создания эквалайзера микрофона без задержек.
