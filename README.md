🟣 Ultimate Stream Overlay [Twitch & OBS]
Премиальный, модульный и полностью интерактивный оверлей для стримеров на Twitch.
Написан на чистом HTML/CSS/JS, без использования конструкторов типа Streamlabs или StreamElements. Работает молниеносно, сохраняет данные при перезагрузке и управляется прямо из чата!
✨ Главные фишки
🦊 Интерактивный Питомец (Stream Avatar): Пиксельная лисичка сидит на рамке вебки и реагирует на стрим: засыпает в тишине, пугается твоих смертей в играх, танцует от спама смайлов, злится на мат в чате и пускает сердечки при подписках!
💾 Защита от перезагрузок (LocalStorage): Очередь музыки, счетчик смертей и аватарки зрителей кэшируются прямо в OBS. Если моргнет интернет или ты обновишь источник — ничего не пропадет!
📺 Серии просмотров (Watch Streaks): Оверлей умеет ловить системные сообщения Twitch и выводить красивые неоновые алерты для зрителей, которые смотрят тебя много стримов подряд.
🎙️ Озвучка чата (TTS): Встроенный синтезатор речи с поддержкой кастомных голосов (тональность и скорость) для избранных зрителей.
🎵 Интерактивный плеер YouTube: Заказы музыки за Баллы Канала. Скрипт сам проигрывает видео, показывает прогресс-бар и переключает треки.
💬 Умный Чат: Плавная анимация, парсинг всех Twitch-эмодзи и система блюра запрещенных слов (защита от банов).
🛠️ Как настроить перед запуском
Открой файл js/config.js через любой текстовый редактор.
Что нужно обязательно изменить:
channelName: "ТВОЙ_НИК" — впиши свой ник на Twitch (маленькими буквами).
rewardName: "Заказать видео" — для заказов музыки создай награду на Twitch с точно таким же названием.
ttsRewardName: "Озвучить сообщение" — награда для голосовой озвучки (TTS).
🎤 Настройка пульсирующей вебки (ВАЖНО!)
Чтобы рамка веб-камеры пульсировала в такт твоему голосу, нужно правильно настроить Windows и OBS:
В Windows (возле часов) нажми правой кнопкой на звук -> Звуки -> Вкладка Запись.
Убедись, что твой стримерский микрофон установлен как «Устройство по умолчанию».
В свойствах источника «Браузер» в OBS СНИМИ галочку «Управление аудио через OBS» и ПОСТАВЬ галочку «Обновлять браузер, когда сцена становится активной».
📺 Установка в OBS Studio
Добавлять оверлей нужно через источник «Браузер» (Browser Source). Размер для всех ссылок строго 1920x1080!
Можно добавить всё одной ссылкой (index.html), но рекомендуется модульный подход — добавь каждый элемент как отдельный источник:
Чат: .../index.html?widget=chat
Алерты: .../index.html?widget=alerts
Музыкальный плеер: .../index.html?widget=music
Цель (Goal): .../index.html?widget=goal
Рамка Вебки (Эквалайзер): .../index.html?widget=cam
Пиксельный питомец (Лиса): .../index.html?widget=pet
Социальные сети: .../index.html?widget=socials
Счетчик смертей: .../index.html?widget=deaths
Бегущая строка: .../index.html?widget=ticker
Shoutout (Реклама стримеров): .../index.html?widget=shoutout
Фон (Частицы): .../index.html?widget=particles
💡 Для сцены "Just Chatting" (где вебка большая), добавляй к ссылке &scene=chatting (например: .../index.html?widget=pet&scene=chatting). Элементы автоматически встанут на нужные места.
🎮 Команды Чата
Оверлей слушает чат Twitch в реальном времени.
🟢 Для всех зрителей:
!play [ссылка] или !sr [ссылка] — добавить трек в очередь (если включено).
🔴 Только для Модераторов и Стримера:
🎥 Вебкамера и Визуал:
!game [название] — показать логотип игры над вебкой (названия берутся из config.js, например !game subnautica).
!game off (или hide) — убрать логотип игры с экрана.
!cam off / !cam on — скрыть или показать рамку веб-камеры.
!mic off / !mic on — выключить/включить реакцию рамки на голос (или перезагрузить эквалайзер).
!emotes a (или bubble) — режим эмодзи: летящие пузыри.
!emotes b (или fountain) — режим эмодзи: фонтан.
!emotes off / !emotes on — полностью выключить/включить летящие смайлы на экране.
💀 Счетчик смертей (сохраняется при перезагрузке):
!death (или !смерть) — +1 смерть (питомец испугается, счетчик затрясется).
!death - — отнять 1 смерть.
!death set [число] — установить точное количество (например: !death set 15).
!death reset — сбросить счетчик до нуля.
!death hide / !death show — принудительно спрятать или показать счетчик.
🎵 Музыка и TTS:
!skip — пропустить трек.
!clear — очистить всю очередь заказов.
!vol [0-100] — громкость музыки.
!tts [текст] — бесплатная озвучка сообщения (только для модеров).
!tts stop — заткнуть бота (если заказали слишком длинный/раздражающий текст).
🔔 Инструменты стримера:
!so @никнейм — красивая 3D-карточка рекламы другого стримера на экране.
!alert — тест фолловера.
!alert sub — тест подписки.
!alert resub — тест переподписки.
!alert gift — тест подарочной подписки.
!alert streak — тест серии просмотров (Watch Streak).
⚙️ Технологии под капотом
ComfyJS — подключение к Twitch чату (WebSockets).
YouTube Iframe API — музыкальный плеер.
IVR API (api.ivr.fi) — аватарки и данные пользователей (работает без токенов Twitch).
Web Audio API — эквалайзер микрофона.
Web Speech API — система TTS с поддержкой питча и скорости.
HTML5 LocalStorage — защита данных стрима от перезагрузки OBS.
